# Nova Versão 0.0.1.2 BUILD - BETA

**Versão**: 0.0.1.2 BUILD - BETA  
**Data de Lançamento**: 11/11/2024

## Descrição

Esta versão é um build beta focado na melhoria da interface de usuário e usabilidade para o processo de adição de jogos na plataforma **Kinkler**. As principais atualizações incluem a redefinição do layout da página de **"Adicionar Jogo"** para um design mais clean e moderno, similar ao da página de login, com melhoria no estilo dos campos de entrada e do botão de ação.

## Mudanças principais

### Página "Adicionar Jogo":
- **Redefinição do design** com layout centralizado.
- **Campos de entrada sem borda**, com foco em um design mais limpo.
- **Melhoria no campo de texto e link de imagem** (com borda roxa ao focar).
- **Adição de sombras sutis** para os campos de entrada e do formulário, garantindo um efeito de destaque.

### Página de Login (Referência):
- Página **centralizada** com um fundo cinza esfumado.
- Campos de entrada com **bordas roxas** ao focar.
- **Botão de login** com efeito de mudança de cor ao passar o mouse.

### Aprimoramento do formulário de adição de jogos:
- Inclusão dos campos: **Nome do Jogo**, **Descrição**, **Link** e **Imagem (URL)**.
- Implementação de um novo esquema de **estilização para os inputs e botões**, com o foco em facilitar a experiência do usuário.

### Correções de UI:
- **Remoção de bordas desnecessárias** nos campos de input.
- Ajustes na **responsividade** e **centralização** dos elementos na tela.
- Melhoria na **cor do texto** e nos **contrastes**, priorizando uma estética mais limpa e moderna.
